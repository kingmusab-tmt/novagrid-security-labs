# Episode 12 — Triage Suspicious Traffic (Wireshark)

**Season 2 · Under attack · difficulty: intermediate**

packet capture. Open it in Wireshark, find the infected host, reconstruct how it got
infected and where it's calling home, pull the IOCs, and write the network-analysis report.

**Real data:** this lab runs on a genuine malware capture from
**malware-traffic-analysis.net** (Brad Duncan's archive). Artifact: a network-analysis
report + IOCs.
