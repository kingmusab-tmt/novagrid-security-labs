# Episode 6 — Classify NovaGrid's Data

**Season 1 · Foundations · difficulty: beginner**
**Security+ SY0-701:** 1.0 General Concepts (data types & classification) · 5.0 Governance

Regulators want to know what sensitive data NovaGrid holds and where. Define a
classification scheme, then actually go find the data — scan the lab for PII and
cardholder-style data — and build a data inventory with handling rules. Artifact: a data
classification scheme + inventory.
