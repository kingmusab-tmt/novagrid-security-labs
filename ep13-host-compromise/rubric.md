# Rubric — Episode 13 (100 pts)

| Area | What "good" looks like | Pts |
|------|------------------------|-----|
| Data mapping | Enumerated sourcetypes; chose the right ones per stage | 10 |
| Timeline | Correct, ordered kill chain with timestamps | 20 |
| Recon & brute force | Scanner + attacker IP identified; brute force + successful password confirmed from data | 20 |
| Exploitation & malware | Malicious file named; hash pulled and enriched | 15 |
| IOCs | Complete, correctly typed, with how-found | 10 |
| ATT&CK mapping | Techniques match the evidence (not guessed) | 10 |
| Response | Realistic contain / eradicate / recover / prevent | 10 |
| Reflection | Specific and honest | 5 |

**Evidence required in `evidence/`:** the sourcetype map, a screenshot per kill-chain stage
(SPL + result), the IOC list, one enrichment, and the timeline. Missing evidence caps the area.
