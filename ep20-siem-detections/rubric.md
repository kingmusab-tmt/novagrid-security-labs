# Rubric — Episode 20 (100 pts)

| Area | What "good" looks like | Pts |
|------|------------------------|-----|
| Coverage | A working detection for all five kill-chain stages | 20 |
| SPL correctness | Each search runs and returns the known-bad events | 20 |
| Detection logic | Clear why each works; right data source chosen | 15 |
| FP tuning | Realistic false-positive analysis + mitigation per detection | 15 |
| Severity & response | Sensible severity and a concrete analyst response each | 10 |
| ATT&CK mapping | Techniques match the detections | 10 |
| Validation evidence | Screenshots of each detection firing + ≥2 saved-alert configs | 10 |

**Bonus (up to +10):** Sigma versions of the rules, or a risk-based correlation alert.
Missing validation evidence caps SPL/validation areas.
