# Instructor Answer Key — Episode 28
- Red flags in the profile: SOC 2 **Type I only** (design, not operating effectiveness — demand Type II), no pen-test summary, undisclosed subcontractors (fourth-party risk), and a data-residency/cross-border issue (NDPR).
- SOC 2 Type I = controls designed at a point in time; Type II = controls operating effectively over a period (stronger). A questionnaire (SIG/CAIQ) probes specifics a cert's scope may omit.
- Contract must-haves: right-to-audit, breach notification (≈72h), data ownership/handling/return/destruction, subcontractor controls, SLAs.
- Ongoing monitoring: periodic re-assessment + continuous monitoring + exit plan ("assessed once ≠ trusted forever").
- Verification: (1) Type I vs II; (2) three clauses + why; (3) post-onboarding monitoring.
