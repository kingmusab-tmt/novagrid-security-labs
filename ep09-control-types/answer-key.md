# Instructor Answer Key — Episode 9
- Category = the *nature* of the control (Technical, Managerial, Operational, Physical).
- Type = what it *does* (Preventive, Deterrent, Detective, Corrective, Compensating, Directive).
- Compensating control = an alternative when the primary control isn't feasible (e.g. extra
  monitoring/read-only access for a legacy system that can't support MFA).
- Common gaps at end of Season 1: real-time alerting (only passive logs), DLP, automated correction.
- Verification: (1) category vs type; (2) compensating-control example; (3) a real gap + fix.
